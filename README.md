# Coin Battle — MVP starter

Русскоязычная основа Telegram Mini App: React/Vite + Express + Prisma + PostgreSQL.

## Что уже заложено
- Telegram WebApp initData validation на сервере (не доверяем Telegram ID из клиента).
- Профиль, COIN, XP и прокачка характеристик.
- Расширяющийся поиск соперника по XP.
- После 60 секунд — предложение боя с явно обозначенным ботом.
- Бот ориентировочно на 5–10% сильнее по боевой силе и выбирает тактику.
- Подтверждение боя с ботом до начала.
- Серверная симуляция хода: клиент не сообщает серверу, кто победил.
- PostgreSQL/Prisma schema.

## Важно
Это MVP-каркас для разработки и тестирования, а не готовый production-релиз. Очередь PvP в этом шаблоне локальная (в памяти одного процесса); перед публичным запуском её нужно перенести в Redis или PostgreSQL с блокировками. Экономику ставок, антифрод, полноценный realtime PvP, платежи, аудит и нагрузочное тестирование нужно завершить отдельно. Пока не включайте реальные деньги/ценные токены.

## Требования
- Node.js 20+
- PostgreSQL 15+
- Telegram-бот, созданный через @BotFather
- HTTPS-домен для публичного запуска

## Запуск локально
1. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `DATABASE_URL`.
2. В корне выполните:
   ```bash
   npm install
   npm run db:generate
   npm run db:migrate
   ```
3. В одном терминале:
   ```bash
   npm run dev:server
   ```
4. Во втором терминале:
   ```bash
   npm run dev:client
   ```
5. Для проверки Telegram Mini App откройте приложение через кнопку меню бота. Обычный браузерный режим предусмотрен только как локальный preview.

## Что нужно привязать тебе
1. Создать бота в @BotFather и получить токен.
2. Создать PostgreSQL базу у облачного провайдера.
3. Задать `BOT_TOKEN`, `DATABASE_URL`, `WEBAPP_URL` в переменных окружения хостинга.
4. Развернуть сервер и frontend на HTTPS.
5. В @BotFather настроить Menu Button / Web App URL.
6. Проверить авторизацию, миграции и тестовые матчи.
7. Перед включением ставок — согласовать правила, юридические требования и политику возвратов для страны запуска.
