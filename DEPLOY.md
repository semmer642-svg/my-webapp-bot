# Пошаговое подключение Coin Battle

## 1. Telegram
- Открой Telegram и найди `@BotFather`.
- Выполни `/newbot`, задай имя и username.
- Сохрани токен. Не отправляй его в чат и не добавляй в Git.
- После публикации HTTPS frontend укажи его как Web App URL через настройки бота / Menu Button.

## 2. База данных
Создай PostgreSQL 15+ у выбранного облачного провайдера. Скопируй connection string в `DATABASE_URL`.
Используй отдельную базу для production и staging.

## 3. Переменные окружения
Заполни значения из `.env.example` в настройках backend-хостинга:
- `BOT_TOKEN` — токен BotFather.
- `DATABASE_URL` — PostgreSQL URL.
- `WEBAPP_URL` — публичный HTTPS URL frontend.
- `PORT` — порт, который предоставляет хостинг.

Никогда не публикуй `.env`, токен бота или секреты в репозитории.

## 4. Запуск
Локально:
```bash
npm install
npm run db:generate
npm run db:migrate
npm run dev:server
npm run dev:client
```
Production-команды:
```bash
npm run build
npm run start
```
Backend должен быть доступен по HTTPS или за HTTPS reverse proxy. Frontend должен проксировать `/api` на backend (пример Vite proxy есть в `client/vite.config.ts`).

## 5. Проверки перед тестом
- Открывать приложение через Telegram, а не только по прямой ссылке.
- Проверить вход двух разных Telegram-аккаунтов.
- Проверить, что повторная отправка одного запроса не начисляет награду повторно.
- Проверить очередь PvP на двух устройствах.
- Проверить отказ от боя с ботом: ставка не списывается.
- Проверить, что сервер, а не браузер, рассчитывает исход боя.
- Включить резервные копии БД и мониторинг ошибок.

## 6. Что не включать пока
- Реальные деньги, вывод средств и внешний токен.
- Ставки против ботов без отдельного явного согласия и раскрытых правил.
- Покупки сундуков за деньги до завершения антифрода, возвратов и юридической проверки.

## 7. Надёжность
Для 24/7 нужен постоянно работающий backend, управляемая PostgreSQL, резервные копии, мониторинг и автоматический перезапуск. Бесплатные тарифы могут засыпать или иметь лимиты; гарантировать 100% доступность нельзя.
